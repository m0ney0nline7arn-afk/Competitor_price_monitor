# Competitor Price Monitor

A Python project for collecting, processing, and monitoring competitor prices.

## Goals

- Collect product prices from permitted sources.
- Normalize and store collected data.
- Track price changes.
- Prepare reports.
- Send notifications about significant changes.

## Tech Stack

- Python
- Requests
- BeautifulSoup4
- Pandas
- Pydantic
- Pytest
- Ruff
